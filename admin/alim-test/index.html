먼저 홈 화면에 추가해 주세요

아이폰은 홈 화면 아이콘으로 열어야 알림을 받을 수 있어요.

  1. 사파리로 이 페이지를 열어요.
  2. 아래 가운데 공유 버튼을 눌러요.
  3. "홈 화면에 추가"를 눌러요.
  4. 새로 생긴 "알림 시험" 아이콘으로 다시 열어요.

  • 기기확인 중

1. 알림 허용하기

누르면 폰이 "알림을 허용할까요?"라고 물어요. 허용을 눌러 주세요.

2. 이 폰에서 바로 울려 보기

알림 모양, 소리, 진동을 봐요. 누른 뒤 홈 화면으로 나가도 돼요.

3. 앱을 꺼 둔 채로 받기

[복사하기]를 누르고, 카톡으로 액상덕후에게 붙여서 보내 주세요. 그다음 이 앱을 닫고 기다리면 알림이 와요.
