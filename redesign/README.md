## ⚠ 지금 맞지 않는 것

`aekduk-custom.css`와 `home.html`이 **정반대 문법**입니다.

| | `aekduk-custom.css` (기존) | `home.html` (신규) |
|---|---|---|
| 모서리 | **각짐** (`border-radius: 0`) | **둥긂** (카드 24px) |
| 버튼 | 각진 사각 | 알약형 |
| 드롭다운 | 2px 검정 테두리, 그림자 없음 | — |
| 톤 | 밝음 (요헤미티 이식) | 어두움 (감각적) |

기존 CSS는 요헤미티를 참조하던 단계에서 만든 것이고, 이후 **"예뻐야 한다"**는
방향 전환이 있었습니다. 둘 중 하나로 통일해야 합니다.

**색 팔레트는 이미 같습니다** — `#FF2D6F` `#F3F2EF` `#C4005C` `#111111`.
바꿔야 하는 건 모서리·그림자·톤이지 색이 아닙니다.

## 방향

**포지션: "니코틴 없어도 맛있다"**

경쟁사 레딜은 *"니코틴 없어서 안전하다"*를 팝니다. 그래서 화면이 밝고 임상적이에요.
우리는 반대로 **맛**을 팝니다. 같은 무니코틴이라도 파는 이유가 다르면 화면이
달라야 합니다.

### 지면 구성

```
검정 헤더          ← 전 페이지 고정
  히어로 (검정)
  상품 (오프화이트)   ← 사진 색이 정확히 보여야 하는 구간
  0mg (검정)
  맛 계열 (오프화이트)
  후기 (검정)
검정 푸터          ← 전 페이지 고정
```

**헤더·푸터가 검정으로 고정되면 가운데가 밝아도 같은 사이트로 읽힙니다.**
전 페이지 통일의 핵심은 배경색이 아니라 이 위아래입니다.

### 상품마다 다른 색

포인트 핑크 하나로 몰지 않았습니다. 카드 뒤에서 **맛에 맞는 색**이 번집니다.
액상은 맛이 곧 색이라, 13종이 전부 같은 색이면 다 똑같아 보입니다.

## 투자 배분

아임웹은 홈 같은 커스텀 페이지는 자유롭지만, 상품 리스트·상세·장바구니·주문서는
**시스템 페이지라 CSS로 색만 덮을 수 있고 구조는 못 바꿉니다.**

이건 제약이 아니라 정상입니다. 참고로 레딜(카페24)도 SHOP 페이지는 기본 스킨
거의 그대로예요 — `조건별 검색`, `제조사` 정렬, 안 쓰는 `WORLD SHIPPING`
200개국 목록이 그대로 남아 있고 색상도 전부 무채색입니다.
**메인만 공들이고 상품 페이지는 기본값**이라는 뜻입니다.

| 페이지 | 작업 |
|---|---|
| 홈 · 브랜드 소개 | 직접 제작 |
| 상품 리스트 · 상세 | 아임웹 기본 + CSS만 |
| 장바구니 · 주문 · 결제 | 손대지 않음 |

결제 화면이 어두우면 신뢰도가 떨어집니다. 거래 구간을 밝게 두는 건 정석입니다.

## 상품 카드

레딜 카드의 정보량에 맞춰 가볍게 잡았습니다.

```
이미지
[무무]                    ← 브랜드
제로닉 샤인머스캣            ← 제품명
샤인머스캣                  ← 맛
───────────────
멘솔            14,000원
```

맛 세기 게이지(단맛·청량감·묵직함)를 넣었다가 **뺐습니다.** 실제 수치가 없어
지어내야 했기 때문입니다. 13종의 세기를 정해주시면 그때 넣겠습니다.

## 확인 · 결정 필요

- [ ] **CSS 문법 통일** — 각진 방향 vs 둥근 방향 (위 ⚠ 참조)
- [ ] **가격** — 지금 전부 `14,000원` 임시값
- [ ] **제품 사진** — 카드 이미지 자리가 비어 있음
- [ ] **PG사 심사** — 전자담배·액상 업종은 결제대행 심사가 까다롭습니다.
      무니코틴이어도 업종 코드로 거절되거나 보증금을 요구받는 경우가 있어
      아임웹 유료 결제 전에 확인 권장
- [ ] **취급 범위** — 레포 데이터 312종 중 무니코틴은 13종뿐입니다.
      나머지 257종(니코틴 함유)도 파실 건지에 따라 사이트 구조가 달라집니다

## 데이터 출처

`liquids-nicotine-free.json`은 레포 `liquid.html`의 `D_FALLBACK` 배열에서
`무니코틴` 태그가 붙은 항목만 추린 것입니다. 필드는 원본 그대로:

| 키 | 뜻 |
|---|---|
| `n` | 제품명 |
| `b` | 브랜드 (무무 11종 / 무 2종) |
| `c` | 라인 (전부 프리미엄 라인) |
| `t` | 태그 (무니코틴 / 노멘솔) |
| `f` | 맛 |

가격과 맛 세기는 원본에 없습니다.
