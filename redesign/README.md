## 시각 문법: 요헤미티 (각짐)

`home.html`은 `aekduk-custom.css`와 같은 문법으로 다시 짰습니다.

| | 값 |
|---|---|
| 모서리 | `border-radius: 0` — 전부 각짐 |
| 구조선 | `2px solid #000` |
| 그림자 | 없음 |
| 지면 | 오프화이트 `#F3F2EF` / 음영 `#E7E5E0` |
| 어두운 면 | `#141414` — 유틸바 · 0mg 섹션 · CTA · 푸터 |
| 포인트 | `#FF2D6F` (hover·CTA) / `#C4005C` (작은 글씨) |

그리드는 셀마다 `border-right`·`border-bottom`을 주고 컨테이너에 `border-top`·
`border-left`를 줘서 선이 겹치지 않게 했습니다. 칩과 버튼은 `margin-left:-2px`로
테두리를 공유합니다.

**아임웹 CSS를 다시 쓸 필요가 없습니다.** 색·모서리·선 두께가 이미 일치합니다.

## 구조: 레딜 뼈대

섹션 순서는 레딜 홈에서 가져왔습니다. 무니코틴 브랜드몰의 표준 문법이라
베끼기가 아닙니다. 문제가 되는 건 시각 표현인데, 그쪽은 요헤미티 문법이라
결과적으로 둘 중 어느 쪽도 닮지 않습니다.

```
히어로 → 0mg 선언 → 상품 → [노멘솔] → [큐레이션] → 후기 → FAQ → CTA
                              ↑ 레딜의 취향그룹·TRUST 자리를 우리 것으로 교체
```

### 레딜에 이미 있는 것은 가져오지 않는다

레딜 홈 저장본을 뜯어보니 다음이 **이미 있었습니다.**

- 맛 게이지 3축 (`달콤함` / `상큼함` / `묵직함`) + `타격감 VERY STRONG` 뱃지
- 취향 그룹 3분류 (`IMPACT` / `DAILY` / `DEEP`)

앞서 이 둘을 "우리 차별점"으로 잡았던 것은 오판이었습니다. 넣으면 그대로
베끼기가 되므로 **뺐습니다.**

### 대신 레딜이 가질 수 없는 축으로

| 축 | 왜 레딜은 못 하나 |
|---|---|
| **노멘솔 6종** | 레딜 라인업엔 이 구분 자체가 없다 |
| **여러 브랜드 큐레이션** | 자사 제품만 팔아서 고를 게 하나뿐이다 |

무니코틴 액상은 대부분 멘솔입니다. 청량감으로 니코틴의 빈자리를 메우기
쉬워서요. 그래서 노멘솔을 찾는 사람은 선택지가 없고, 이게 우리 자리입니다.

### 지면 리듬

```
검정 유틸바        ← 전 페이지 고정
  헤더 (오프화이트, 아래 2px 검정선)
  히어로 (오프화이트 · 좌우 분할 격자)
  0mg 선언 (검정)          ← 지면 반전 1
  상품 13종 (오프화이트)
  노멘솔 (오프화이트 음영)
  큐레이션 (오프화이트)
  후기 (오프화이트 음영)
  FAQ (오프화이트)
  CTA (검정)               ← 지면 반전 2
검정 푸터          ← 전 페이지 고정
```

밝은 지면이 기본이고, **0mg 선언과 최종 CTA 두 곳만 검정으로 반전**시킵니다.
가장 중요한 두 지점이라 여기서만 씁니다.

### 상품마다 다른 색

포인트 핑크 하나로 몰지 않았습니다. 카드 이미지 자리에 **맛에 맞는 색면**이
깔립니다. 액상은 맛이 곧 색이라, 13종이 전부 같은 색이면 다 똑같아 보입니다.

각진 문법이라 흐릿한 그라데이션 대신 **단색 면**으로 처리했습니다.
노멘솔 섹션의 색 막대도 같은 값을 씁니다.

## 투자 배분

아임웹은 홈 같은 커스텀 페이지는 자유롭지만, 상품 리스트·상세·장바구니·주문서는
**시스템 페이지라 CSS로 색만 덮을 수 있고 구조는 못 바꿉니다.**

이건 제약이 아니라 정상입니다. 참고로 레딜(카페24)도 SHOP 페이지는 기본 스킨
거의 그대로예요 — `조건별 검색`, `제조사` 정렬, 안 쓰는 `WORLD SHIPPING`
200개국 목록이 그대로 남아 있고 색상도 전부 무채색입니다.
**메인만 공들이고 상품 페이지는 기본값**이라는 뜻입니다.

| 페이지 | 작업 |
|---|---|
| 홈 · 브랜드 소개 | 직접 제작 |
| 상품 리스트 · 상세 | 아임웹 기본 + CSS만 |
| 장바구니 · 주문 · 결제 | 손대지 않음 |

결제 화면이 어두우면 신뢰도가 떨어집니다. 거래 구간을 밝게 두는 건 정석입니다.

## 상품 카드

레딜 카드의 정보량에 맞춰 가볍게 잡았습니다.

```
이미지
[무무]                    ← 브랜드
제로닉 샤인머스캣            ← 제품명
샤인머스캣                  ← 맛
───────────────
멘솔            14,000원
```

맛 세기 게이지(단맛·청량감·묵직함)를 넣었다가 **뺐습니다.** 실제 수치가 없어
지어내야 했기 때문입니다. 13종의 세기를 정해주시면 그때 넣겠습니다.

## 데이터 출처

`liquids-nicotine-free.json`은 레포 `liquid.html`의 `D_FALLBACK` 배열에서
`무니코틴` 태그가 붙은 항목만 추린 것입니다. 필드는 원본 그대로:

| 키 | 뜻 |
|---|---|
| `n` | 제품명 |
| `b` | 브랜드 (무무 11종 / 무 2종) |
| `c` | 라인 (전부 프리미엄 라인) |
| `t` | 태그 (무니코틴 / 노멘솔) |
| `f` | 맛 |

가격과 맛 세기는 원본에 없습니다.
