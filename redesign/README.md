## 방향

**포지션: "니코틴 없어도 맛있다"**

경쟁사 레딜은 *"니코틴 없어서 안전하다"*를 팝니다. 그래서 화면이 밝고 임상적이에요.
우리는 반대로 **맛**을 팝니다. 그래서 어둡고 감각적으로 갑니다. 같은 무니코틴이라도
파는 이유가 다르면 화면이 달라야 합니다.

### 색

| 용도 | 값 |
|---|---|
| 바탕 (브랜드 구간) | `#0A0A0B` |
| 바탕 (상품 구간) | `#F3F2EF` |
| 포인트 | `#FF2D6F` |
| 밝은 배경용 포인트 | `#C4005C` |

포인트 핑크 하나로 몰지 않았습니다. **상품마다 맛에 맞는 색**이 카드 뒤에서 번지게
했어요. 액상은 맛이 곧 색이라, 13종이 전부 같은 색이면 다 똑같아 보입니다.

### 지면 구성

```
검정 헤더          ← 전 페이지 고정
  히어로 (검정)
  상품 (오프화이트)   ← 사진 색이 정확히 보여야 하는 구간
  0mg (검정)
  맛 계열 (오프화이트)
  후기 (검정)
검정 푸터          ← 전 페이지 고정
```

**헤더·푸터가 검정으로 고정되면 가운데가 밝아도 같은 사이트로 읽힙니다.**
전 페이지 통일의 핵심은 배경색이 아니라 이 위아래입니다.

## 플랫폼: 카페24

레딜도 카페24입니다 (`redill.co.kr/product/{상품명}/{번호}/` — 카페24 고유 URL 형식).
같은 업종에서 결제 심사를 통과한 전례가 있다는 뜻이라 이쪽으로 정했습니다.

### 투자 배분

레딜 SHOP 페이지 저장본을 뜯어본 결과 **카페24 기본 스킨 거의 그대로**였습니다.
`조건별 검색`, `제조사` 정렬, 안 쓰는 `WORLD SHIPPING` 200개국 목록이 그대로 남아
있어요. 색상도 전부 무채색(`#000` `#333` `#808080`)입니다.

즉 **레딜조차 메인만 공들이고 SHOP은 기본값**입니다. 우리도 같은 배분으로 갑니다.

| 페이지 | 작업 |
|---|---|
| 홈 | 직접 제작 (`home.html`) |
| SHOP · 상품 상세 | 카페24 기본 + CSS만 |
| 장바구니 · 주문 · 결제 | 손대지 않음 |

결제 화면이 어두우면 신뢰도가 떨어집니다. 거래 구간을 밝게 두는 건 타협이 아니라
정석입니다.

## 상품 카드

레딜 카드에 담긴 정보량에 맞췄습니다.

```
이미지
[무무]                    ← 브랜드
제로닉 샤인머스캣            ← 제품명
샤인머스캣                  ← 맛
───────────────
멘솔            14,000원
```

맛 세기 게이지(단맛·청량감·묵직함)를 넣었다가 **뺐습니다.** 실제 수치가 없어서
지어내야 했기 때문입니다. 사장님이 13종의 세기를 정해주시면 그때 넣겠습니다.

## 확인 · 결정 필요

- [ ] **가격** — 지금 전부 `14,000원` 임시값입니다
- [ ] **제품 사진** — 카드 이미지 자리가 비어 있습니다. 컬러 오라와 겹치면 살아납니다
- [ ] **PG사 심사** — 전자담배·액상 업종은 결제대행 심사가 까다롭습니다.
      무니코틴이어도 업종 코드로 거절되거나 보증금을 요구받는 경우가 있어
      카페24 계약 전에 확인이 필요합니다
- [ ] **취급 범위** — 레포 데이터 312종 중 무니코틴은 13종뿐입니다.
      나머지 257종(니코틴 함유)도 파실 건지에 따라 사이트 구조가 달라집니다

## 데이터 출처

`liquids-nicotine-free.json`은 레포 `liquid.html`의 `D_FALLBACK` 배열에서
`무니코틴` 태그가 붙은 항목만 추린 것입니다. 필드는 원본 그대로:

| 키 | 뜻 |
|---|---|
| `n` | 제품명 |
| `b` | 브랜드 (무무 11종 / 무 2종) |
| `c` | 라인 (전부 프리미엄 라인) |
| `t` | 태그 (무니코틴 / 노멘솔) |
| `f` | 맛 |

가격과 맛 세기는 원본에 없습니다.
