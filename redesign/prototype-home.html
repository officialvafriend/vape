01 — 팔레트

포인트는 딱 한 곳에만 쓴다

요헤미티가 세련돼 보이는 이유는 색을 많이 써서가 아니라 거의 안 쓰기 때문입니다. 화면의 95%가 흑백이고 주황은 hover와 active에만 튀어나옵니다. 이 원칙을 그대로 가져왔습니다.

오프화이트#F3F2EF기본 지면. 순백(#FFF)보다 살짝 눌러서 제품 사진이 뜨게 만듭니다.

04 — 일정

2주 계획

1~2주 넉넉하다고 하셨으니 2주 기준으로 짰습니다. 클로드는 제가, 사장님은 아임웹 관리자에서 직접 하셔야 하는 작업입니다.

  • DAY 1–2

    디자인 설정 복제 클로드 사장님

    제가 아임웹 관리자 메뉴별 설정값 체크리스트를 드리면, 사장님이 그대로 입력하십니다. 사이트 컬러 · Pretendard · 헤더 오버레이 2단 · 푸터 타입05 · 섹션 폭 1080px.

  • DAY 2

    커스텀 CSS 삽입 클로드

    각진 2px 검정 드롭다운, 헤더 오버레이 보정, 핑크 포인트 치환. 제가 코드 한 덩어리로 써드리면 [디자인 → 코드 삽입]에 붙여넣기만 하시면 됩니다.

  • DAY 3–5

    이미지 제작 — 여기가 전체의 70% 클로드

    히어로 1064×213, 대형 배너 1064×553, 제품 카드 344×464, 가이드 카드 344×344, 섹션 타이틀. 제가 HTML/SVG로 만들어 PNG로 뽑아드리거나, 연결된 Canva로 바로 제작 가능합니다.

  • DAY 6–8

    PC 섹션 조립 사장님

    이미지 + 여백 위젯만 반복 배치. 위젯별 여백값은 제가 표로 드립니다. 애니메이션은 fadeIn / fadeInUp, 0.6초.

  • DAY 9–11

    모바일 섹션 조립 사장님

    전폭 섹션으로 별도 제작. 여기가 제일 지루한 구간이라 여유를 뒀습니다.

  • DAY 12–13

    상품 리스트 · 상세 페이지 클로드 사장님

    쇼핑몰 핵심 화면입니다. 다만 지금 이 부분 자료가 없습니다 — 아래 요청 참고.

  • DAY 14

    기기 테스트 · 오픈 사장님

    아이폰 · 안드로이드 · 노트북에서 확인. 특히 오버레이 헤더가 스크롤 시 제대로 채워지는지.

06 — 다음 단계

지금 필요한 것 두 가지

  1. 이 팔레트 승인 — 위 핑크(#FF2D6F)가 마음에 드시는지. 더 진하게/연하게 조정 가능합니다.
  2. 상품 페이지 저장본 — 요헤미티 /product3 또는 상품 상세 페이지를 메인 때처럼 Ctrl+S → "웹페이지, 전체"로 저장해서 주세요. 쇼핑몰의 진짜 핵심인 상품 리스트·상세 레이아웃이 메인 페이지에는 안 들어있습니다.

둘 다 주시면 바로 아임웹 설정 체크리스트 + 커스텀 CSS 전체 코드부터 써드리겠습니다.
