## STEP 3 — 헤더 (제일 중요)

*위치: 디자인 모드 → 헤더 영역 클릭 → 헤더 설정*

### 3-0. 시작 템플릿 — BLANK. (유틸바 + 로고 좌측형)

헤더 템플릿 목록에서 **국기/Login·Register·Cart·Order·Search 유틸바 + 아랫줄 좌측 `BLANK.` 로고**
형태를 고릅니다. 유틸바 + 1줄 헤더 + 로고 좌측, 세 가지가 요헤미티와 같아 손이 제일 덜 갑니다.

> 신형 헤더는 위젯을 좌/중앙/우 그룹으로 자유롭게 옮길 수 있습니다.
> 어느 템플릿을 골라도 결국 같은 모양을 만들 수 있고, 이건 시작점이 가까울 뿐입니다.

### 목표 배치 (요헤미티 실측)

```
┌──────────────────────────────────────────────────┐
│              [ 상단 알림 — 공지 문구 ]              │  30px · 배경 #141414
├──────────────────────────────────────────────────┤
│ [로고]    [ 구매하기  액덕랩  저널 … ]  [로그인│장바구니] │  63px · 배경 오프화이트
│ 좌 220px         중앙 (메뉴)          우 220px      │
└──────────────────────────────────────────────────┘
```

> **윗줄은 "상단 알림" 기능으로 갑니다. → 헤더는 1단입니다.**
> 요헤미티는 헤더 섹션에 이미지 위젯(1064px PNG, 카카오 채널 추가 링크)을 넣어
> 만들었지만, 문구가 텍스트 한 줄이면 상단 알림 기능이 훨씬 낫습니다.
> 문구를 바꿀 때마다 이미지를 다시 만들 필요가 없습니다.
> 그래픽이 들어간 배너가 필요해지면 그때 이미지 위젯 방식으로 되돌리면 됩니다.

**상단 알림 설정값**

| 항목 | 값 |
|---|---|
| 배경색 | `#141414` |
| 글자색 | `#FFFFFF` |
| 글자 크기 | 11~12px |
| 문구 | 예: `5만원 이상 무료배송 · 오후 3시 이전 결제 시 당일 출고` |
| 닫기 버튼 | 켜기 |

### 3-0-1. 템플릿 → 목표 배치 조정 (이 순서대로)

**① 유틸바 줄 삭제** — 국기·`Login Register Cart Order Search`·SNS 아이콘이 있던
윗줄 섹션을 통째로 삭제합니다. 로고가 있는 줄만 남겨 **1단 헤더**로 만듭니다.

**② 메뉴를 중앙으로** ★ 가장 중요
아랫줄 우측의 메뉴 위젯을 잡아 **중앙 컬럼으로 드래그**.

**③ 우측 유틸 구성** — 비어있는 우측 컬럼에 순서대로:
```
로그인 위젯 → 여백 → 구분선(hr) → 여백 → 장바구니 위젯
```
가운데 세로 구분선이 있어야 `로그인 │ 장바구니`로 떨어집니다.

**④ 로고** — 일단 텍스트로 `액상덕후`. 이미지 로고는 STEP 8에서 제작 후 교체.

### 3-1. 형식

| 항목 | 값 |
|---|---|
| 헤더 종류 | **신형 헤더** |
| 표시 방식 | **오버레이** (첫 섹션 위에 겹침) |
| 고정 | 켜기 (스크롤 시 상단 고정) |
| 구성 | **2단** — 유틸바 + 메인헤더 |
| 좌측 컬럼 폭 | **220px** 고정 |
| 우측 컬럼 폭 | **220px** 고정 |
| 중앙 컬럼 | 자동 (나머지 채움) |

### 3-2. 높이·배경

⚠️ **헤더는 처음부터 불투명합니다.** "투명했다가 스크롤하면 채워지는" 방식이 아닙니다.
오버레이란 헤더가 첫 섹션 *위에 얹힌다*는 뜻이고, 그래서 히어로 섹션 맨 위에
`여백 368px`을 넣어 헤더에 가리지 않게 밀어냅니다. (STEP 7 참고)

> **높이 입력란은 없습니다.** 아임웹 헤더 높이는 `상하 여백 × 2 + 위젯 높이`로 결정됩니다.
> 요헤미티 63px = `11 + 41(메뉴 높이) + 11`. 그래서 **상하 여백에 11**을 넣습니다.

**PC 메인헤더 (63px)** — 섹션 설정 화면의 필드 순서대로

| 필드 | 값 |
|---|---|
| 배경 | 채우기 |
| 배경색 | `#F3F2EF` |
| 텍스트 | `#111111` |
| 가로 100% 확장 | ☐ (1080px 유지) |
| 기본 좌우 여백 | ☐ **해제** → 좌우 여백 `8px` |
| 상하 여백 | **`11px`** |
| 위젯 좌우 간격 | `0px` |
| 세로 정렬 | 중앙 |
| 선두께 | **`0px`** |

> 선두께 주의: 템플릿 기본값 `1px #e7e7e7`이 들어있습니다.
> 요헤미티 헤더는 하단 선이 없습니다(`border-width: 0 0 0px` 확인).
> 남겨두면 헤더 아래 흐린 줄이 생겨 각진 느낌이 죽습니다.

### 3-3. 모바일 헤더 (53px)

아임웹 신형 헤더는 **PC와 모바일이 별개 섹션**입니다.
디자인 모드 상단의 PC/모바일 전환 아이콘으로 바꿔서 따로 편집합니다.

요헤미티 실측 구조 — 로고가 중앙이 아니라 **햄버거 옆 좌측**입니다.

```
┌─────────────────────────────────────┐
│ ☰  액상덕후                      🛒  │   53px · 배경 #F3F2EF
│ └─ 좌 80px ─┘            └ 우 80px ─┘│
└─────────────────────────────────────┘
```

| 위치 | 위젯 순서 |
|---|---|
| 좌 (80px) | 햄버거 → 여백 → 로고 |
| 우 (80px) | 장바구니 |

| 필드 | 값 |
|---|---|
| 배경색 | `#F3F2EF` |
| 텍스트 | `#111111` |
| 좌/우 컬럼 폭 | **80px** |
| 상하 여백 | **`2px`** (→ 높이 53px) |
| 좌우 여백 | `8px` (기본 좌우 여백 해제) |
| 위젯 좌우 간격 | `0px` |
| 세로 정렬 | 중앙 |
| 선두께 | **`0px`** |

> 모바일에도 유틸바 줄이 있으면 삭제합니다. 상단 알림이 모바일에서도 같이 뜹니다.
> 로고는 텍스트로 두세요. 53px 안에 들어가야 해서 PC 로고 이미지는 잘립니다.
> 모바일용 로고 이미지는 STEP 8에서 따로 뽑습니다.

## STEP 7 — 섹션 조립

메인 페이지를 비우셨으니 여기서부터 다시 쌓습니다. **섹션 9개**입니다.

### 방식: 코드 위젯 + 시스템 위젯 섞어 쓰기

아임웹에는 **HTML 코드를 그대로 넣는 위젯**이 있습니다. 이걸 쓰면 시안이
100% 그대로 들어갑니다. 다만 나중에 에디터로 못 고치고 코드를 고쳐야 합니다.

그래서 **내용이 안 바뀌는 곳만 코드 위젯**으로 가고, 계속 바뀌는 곳은
아임웹 시스템 위젯을 씁니다.

| # | 섹션 | 방식 | 붙여넣을 파일 |
|---|---|---|---|

| 2 | 히어로 | **코드 위젯** | `sections/01-hero.html` |
| 3 | 0mg 선언 | **코드 위젯** | `sections/02-zero.html` |

| 5 | 노멘솔 | **코드 위젯** | `sections/03-nomenthol.html` |
| 6 | 취급 브랜드 | **코드 위젯** | `sections/04-curation.html` |
| 7 | 후기 | **아임웹 리뷰 위젯** | — |

**상품·후기·FAQ를 시스템 위젯으로 두는 이유**
상품이 늘거나 후기가 쌓이면 자동으로 화면에 반영돼야 합니다. 코드로 박아두면

### 순서

## STEP 8 — 이미지

**지금 단계에서는 이미지가 없어도 됩니다.**

새 홈은 글자와 격자로 화면을 채우는 방식이라 사진 없이 성립합니다.
상품 카드의 이미지 자리에는 맛에 맞는 **색면**이 깔립니다.

제품 사진이 준비되면 상품 목록 위젯에 등록하시면 자동으로 들어갑니다.

| 용도 | 제작 크기 | 업로드 |
|---|---|---|
| 상품 썸네일 | 1000 × 1000 | 정사각 |
| 상품 상세 | 폭 1000 이상 | 세로 자유 |

모든 이미지는 **2배수(@2x)로 제작 후 업로드**하세요. 레티나 화면에서 흐려집니다.
