| 표기 | 뜻 |

## STEP 6 — 커스텀 CSS 삽입

*위치: 디자인 → 코드 삽입 → HEAD 영역*

1. `redesign/aekduk-custom.css` 파일을 엽니다
2. 전체 복사
3. `<style>` 와 `</style>` 로 **감싸서** HEAD 영역에 붙여넣기
4. 저장 → 사이트 새로고침 → **드롭다운 메뉴에 마우스 올려서 확인**

검은 각진 테두리가 나오고 hover 시 핑크로 차면 성공입니다.
