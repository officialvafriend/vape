# PPOM 스티키 구매 서랍장

`ppom-sticky-purchase-drawer.php`를 Code Snippets 플러그인에 "PHP Snippet" /
"Only run on site front-end"로 등록하세요.

## 사용법

1. **상품 페이지에서만 노출** — `is_product()`로 감싸져 있어서 블로그/장바구니/체크아웃 등
   다른 페이지에는 트리거 바와 오버레이가 아예 출력되지 않습니다. PPOM 옵션(select)이 없는
   상품 페이지에서도 자동으로 숨겨집니다.

2. **상품별 필수 선택 수량 (자동 감지)** — 상품마다 일일이 설정할 필요 없이, PPOM 필드에 이미
   적혀 있는 "4가지 맛을 골라주세요", "13종" 같은 문구에서 숫자를 자동으로 읽어와 필요 수량으로
   사용합니다. 자동 감지가 틀리거나 문구가 없는 상품은 상품 편집 화면 "일반" 탭의
   "서랍장 필수 선택 수량" 입력란에 수동으로 값을 넣으면 그 값이 우선 적용됩니다.
   - 실제 담긴 병 수는 각 선택 항목 아래에 생기는 수량(+/-) 스테퍼 값을 기준으로 계산합니다
     (드롭다운은 항목 추가 후 "선택해주세요"로 리셋되므로 드롭다운 값 자체는 세지 않음).
   - "OO 3+1 묶음 이벤트"처럼 세트/이벤트 자체를 고르는 필드는 병수에 포함하지 않고
     목록에만 표시합니다 (`BUNDLE_PICKER_PATTERN` 정규식으로 "이벤트/묶음/세트/번들" 감지).

3. **PPOM 기본 필드 스타일 정리**
   - PPOM이 재사용하는 WooCommerce 기본 수량(+/-) 스테퍼(`.quantity`, `input.qty`,
     `.minus`/`.plus`)를 서랍장 톤에 맞는 둥근 버튼으로 재도색
   - 선택 항목 이름에 붙는 지저분한 중복 라벨(예: "OO 이벤트 * *: OO 이벤트")을
     `cleanLabelText()`로 정리해서 콜론(:) 뒤쪽 실제 값만 표시
   - 항목 삭제용 "×" 아이콘을 클래스명과 무관하게 찾아 스타일 적용

4. **UI/UX 개선점**
   - 실시간 진행률 바 + 안내 문구("N병 더 선택하면 구매할 수 있어요")
   - 드래그 핸들을 아래로 끌거나 닫기(X) 버튼, 오버레이 탭, ESC 키로 서랍장 닫기
   - iOS Safari 안전영역(`env(safe-area-inset-bottom)`) 대응
   - `setInterval` 폴링 대신 `MutationObserver`로 PPOM 가격 요약 박스를 즉시 제거하고,
     항목이 추가/삭제될 때마다 요약도 자동 재계산(배터리/성능 개선)
   - `role="dialog"`, `aria-modal`, `aria-hidden`, `aria-expanded` 등 접근성 속성 추가
   - 클래스명을 `vf-` 접두사로 통일해 테마/다른 플러그인과의 충돌 최소화

## 참고 / 주의사항

- 데스크톱(≥768px)에서는 서랍장을 만들지 않고 PPOM 기본 UI가 그대로 노출됩니다.
- `$cartForm.find('button, a.button, input[type="submit"]')`로 액션 버튼들을 모두
  하단 액션 영역으로 옮기므로, 장바구니 담기/바로구매 버튼 마크업이 바뀌면 선택자도 함께
  점검해주세요.
- **선택 항목 이름 추출은 추측 기반입니다.** PPOM이 항목마다 어떤 HTML 구조를 쓰는지
  (클래스명 등) 실제로 확인하지 못한 상태로, "수량 스테퍼의 부모 요소의 첫 번째 자식 텍스트"를
  이름으로 사용합니다. 실제 사이트에서 테스트했을 때 이름이 이상하게 나오거나 병수 합산이
  어긋나면, 문제되는 선택 항목 박스 하나를 브라우저 개발자도구(우클릭 → 검사)에서
  outerHTML로 복사해 보내주시면 정확한 선택자로 고칠 수 있습니다.
