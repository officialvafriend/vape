# PPOM 스티키 구매 서랍장

`ppom-sticky-purchase-drawer.php`를 Code Snippets 플러그인에 "PHP Snippet" /
"Only run on site front-end"로 등록하세요.

## 사용법

1. **상품 페이지에서만 노출** — `is_product()`로 감싸져 있어서 블로그/장바구니/체크아웃 등
   다른 페이지에는 트리거 바와 오버레이가 아예 출력되지 않습니다. PPOM 옵션(select)이 없는
   상품 페이지에서도 자동으로 숨겨집니다.

2. **상품별 필수 선택 수량 (자동 감지)** — 상품마다 일일이 설정할 필요 없이, PPOM 필드에 이미
   적혀 있는 문구에서 규칙을 자동으로 읽습니다.
   - "4가지 맛을 골라주세요", "13종" → **최소 N개 이상** 선택해야 활성화
   - "5병 단위로만 구매 가능 하십니다" → **정확히 N의 배수**(5, 10, 15...)여야 활성화 (6처럼
     배수가 아니면 계속 막힘)
   - 자동 감지가 틀리거나 위 문구가 없는 상품은 상품 편집 화면 "일반" 탭의
     "서랍장 필수 선택 수량" 입력란에 값을 넣으면 그 값이 "최소 N개 이상" 규칙으로 우선 적용됩니다.
   - 실제 담긴 병 수는 각 선택 항목 아래에 생기는 수량(+/-) 위젯 값을 화면에 보이는 "−, 숫자, +"
     패턴으로 찾아서 계산합니다(태그/클래스명에 의존하지 않음). 드롭다운 자체는 항목 추가 후
     "선택해주세요"로 리셋되므로 세지 않습니다.
   - "OO 3+1 묶음 이벤트", "[3+2] OO 기획 상품"처럼 세트/이벤트/기획 패키지 자체를 고르는
     필드는 병수에 포함하지 않고 목록에만 표시합니다 (`BUNDLE_PICKER_PATTERN` 정규식으로
     "이벤트/묶음/세트/번들/기획/패키지" 감지).

3. **레이아웃 (v3: 세로 1열로 재설계)**
   - 좌/우 2분할이 답답하고 불편하다는 피드백을 반영해 세로 1열(옵션 → 선택 요약 → 총액 → 버튼)
     흐름으로 전면 재설계했습니다.
   - 글씨/버튼 크기를 전반적으로 키웠습니다 (드롭다운 48px, 수량 스테퍼 40px, 하단 버튼 56px 등).
   - 헤더 전체(드래그 핸들 + 제목 + 닫기 버튼)를 크게 만들어 여닫기가 더 쉬워지도록 했습니다.
   - 버튼이 비활성화 상태일 때 그냥 회색으로 죽어있지 않고, **"2병 더 담아주세요"처럼 버튼 문구
     자체에 이유를 표시**해서 활성화 조건을 바로 이해할 수 있게 했습니다.
   - 선택 요약 상단에 "0 / 4"처럼 분수 배지를 크게 보여주고, 조건을 채우면 초록색으로 바뀝니다.

4. **PPOM 기본 필드 스타일 정리**
   - PPOM이 재사용하는 WooCommerce 기본 수량(+/-) 스테퍼(`.quantity`, `input.qty`,
     `.minus`/`.plus`)를 서랍장 톤에 맞는 둥근 버튼으로 재도색
   - 선택 항목 이름에 붙는 지저분한 중복 라벨(예: "OO 이벤트 * *: OO 이벤트")을
     `cleanLabelText()`로 정리해서 콜론(:) 뒤쪽 실제 값만 표시
   - 항목 삭제용 "×" 아이콘을 클래스명과 무관하게 찾아 스타일 적용

5. **그 외 UI/UX**
   - 헤더를 아래로 끌거나 닫기(X) 버튼, 오버레이 탭, ESC 키로 서랍장 닫기
   - iOS Safari 안전영역(`env(safe-area-inset-bottom)`) 대응
   - `setInterval` 폴링 대신 `MutationObserver`로 PPOM 가격 요약 박스를 즉시 제거하고,
     항목이 추가/삭제될 때마다 요약도 자동 재계산(배터리/성능 개선)
   - `role="dialog"`, `aria-modal`, `aria-hidden`, `aria-expanded` 등 접근성 속성 추가
   - 클래스명을 `vf-` 접두사로 통일해 테마/다른 플러그인과의 충돌 최소화

## 참고 / 주의사항

- 데스크톱(≥768px)에서는 서랍장을 만들지 않고 PPOM 기본 UI가 그대로 노출됩니다.
- `$cartForm.find('button, a.button, input[type="submit"]')`로 액션 버튼들을 모두
  하단 액션 영역으로 옮기므로, 장바구니 담기/바로구매 버튼 마크업이 바뀌면 선택자도 함께
  점검해주세요.
- 선택 항목 이름 추출: 수량 위젯에서 위로 올라가며(최대 25단계, `$cartForm`까지) 한글이 처음
  등장하는 조상 요소를 카드로 보고, 그 카드를 복제해 삭제(×)/수량 위젯/가격 텍스트를 걷어낸
  나머지를 이름으로 씁니다. duck-hoo.com의 실제 3+1/기획/5병단위 상품으로 검증 완료.
- `GATE_ENABLED` (JS 상단)를 `false`로 내리면 병수 조건과 무관하게 구매 버튼이 항상 눌리게
  되는 비상 스위치입니다. 새로운 상품 유형에서 또 오작동하면 우선 이걸로 막고 나서 고치세요.
