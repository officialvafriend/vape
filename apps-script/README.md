# 주간 플레이스 순위 리포트 (자동화)

`weekly-place-report.gs` — 매주 손으로 하던 "기록 확인 → 부진 지점 찾기"를 자동으로 돌립니다.

## 지금 뭐가 문제냐면

순위 스냅샷이 **날짜마다 별도 파일**로 쌓입니다. (`26.08.09`, `26.08.10`, … `26.08.16`)
부진 지점을 찾으려면 파일을 8개 열어서 8지점 × 8키워드 = 64칸을 눈으로 비교해야 해요.
매주 반복되는데 사람이 할 일이 아닙니다.

## 이 스크립트가 하는 일

1. 폴더 안의 날짜별 시트를 **전부** 읽어 하나의 시계열로 합칩니다
2. 일주일 전과 비교해 지점×키워드마다 판정합니다
3. **급한 것만 위로** 정렬해 리포트 시트에 쓰고, 메일로 보냅니다

| 판정 | 뜻 |
|---|---|
| **이탈** | 지난주엔 있었는데 이번주 기록이 없음 — 제일 급함 |
| **권외** | "5위 밖" — 순위권 밖 |
| **하락** | 순위가 내려감 |
| **정체** | 3회 이상 같은 자리에서 안 움직임 (1위 제외) |
| **흔들림** | 시작·끝은 같은데 **주중에 밀렸다 회복** — 자리싸움 중이라는 신호 |
| 상승 / 1위 유지 | 잘 되고 있음 |

"흔들림"이 중요합니다. 8/9과 8/16만 보면 상인점 `대구전자담배`는 1위 → 1위라 조용해 보이는데,
실제로는 주중에 본점한테 뺏겼다가 되찾았어요. 시작·끝만 비교하면 이게 안 보입니다.

## 설치 (5분, 한 번만)

1. 순위 파일이 들어있는 드라이브 폴더를 엽니다
2. 아무 스프레드시트나 하나 열고 → **확장 프로그램 → Apps Script**
3. `weekly-place-report.gs` 내용을 통째로 붙여넣고 저장
4. 맨 위 `CONFIG` 를 채웁니다
   ```js
   RANK_FOLDER_ID: '1IO6QS_05lenXj7yDjEt-wjq7MJZ0JBkC',  // 순위 파일 폴더
   REPORT_SHEET_ID: '',        // 비워두면 처음 실행할 때 새로 만들고 ID를 로그에 찍어줍니다
   MAIL_TO: '',                // 리포트 받을 메일. 비우면 메일 안 보냄
   ```
5. `runWeeklyReport` 를 한 번 실행 → 권한 승인 → 로그에 찍힌 리포트 시트 ID를
   `REPORT_SHEET_ID` 에 넣어두면 다음부터 같은 시트에 쌓입니다

### 매주 자동으로 돌리기

Apps Script 편집기 왼쪽 **⏰ 트리거** → 트리거 추가
→ 함수 `runWeeklyReport`, 유형 **시간 기반**, **주 단위 타이머**, 월요일 오전 9~10시 → 저장

이러면 월요일 아침에 "이번 주 확인 필요 N건"이 메일로 옵니다.

## 시트 형식 (지켜야 돌아갑니다)

- 파일 이름에 `yy.mm.dd` 가 들어갈 것 — `26.08.09`, `26.08.09 플레이스순위` 둘 다 OK
- 첫 시트의 **1행 = 키워드**, **A열 = 매장명**
- 값은 `1위`, `5위 밖`, `-`(추적 안 함), 빈칸

형식이 안 맞는 파일은 **건너뛰고 로그에 남깁니다.** 조용히 빠뜨리지 않으니
실행 후 로그를 한 번 보세요 — 새 파일이 리포트에서 빠져 있으면 거기 이유가 적혀 있습니다.

## 설정값

| 항목 | 기본값 | 설명 |
|---|---|---|
| `COMPARE_DAYS` | 7 | 며칠 전과 비교할지 |
| `STALE_STREAK` | 3 | 몇 회 연속 같은 순위면 '정체'로 볼지 |

## 알아둘 한계

- **네이버 오픈API로는 블로그탭 실순위를 못 잽니다.** 검색 API의 유사도순은 실제 블로그탭
  순위와 다르고 티스토리 등이 대량으로 섞여 들어옵니다. 순위 수집은 지금처럼 외부 도구로
  받아서 시트에 넣는 게 맞습니다. 이 스크립트는 **수집된 값의 비교·판정**만 자동화합니다.
- 네이버 **블로그 글쓰기 API는 2020년 5월 종료**됐고, **스마트플레이스는 공식 API가 없습니다.**
  발행·소식 등록 자동화는 공식적으로 불가능하고, 매크로 우회는 계정 제재 위험이 있습니다.

## 같이 정리하면 좋을 것

- **지점 ↔ 블로그 ID가 자료마다 다릅니다.** 광장코아점이 `ghkffud98`과 `vafriend_gk` 두 가지로,
  현풍점이 `dlfp717`·`bucimgaeqq`·`vafriend_hp08` 세 가지로 기재돼 있습니다.
  어느 게 맞는지 한 곳으로 통일해야 자동화가 지점을 제대로 붙입니다.
- **블로그 계정 비밀번호가 구글시트에 평문으로 들어 있습니다.** 시트 링크를 받은 사람은
  전부 볼 수 있습니다. 비밀번호는 시트에서 빼고 교체하는 걸 권합니다.
